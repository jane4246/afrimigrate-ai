Privacy Lens

AfriMigrate AI demonstrates privacy-by-design through minimum-necessary disclosure.

Information requested for credential verification

The prototype separates information required for verification from information that does not need to be disclosed for the task.

✓ Credential validity SHARE
✓ Purpose SHARE
✓ Country SHARE
✓ Expiry SHARE
✕ Full passport number WITHHOLD
✕ Home address WITHHOLD
✕ Unnecessary private records WITHHOLD
Design principle: disclose only what is necessary for the authorized verification task, with appropriate access controls and auditability in a production deployment.
Purpose limitation

Information should be used for the authorized purpose for which it was requested.

Human oversight

AI-generated guidance should not replace authorized institutional decisions.

Auditability

A production implementation should maintain appropriate access and verification records.

Prototype notice: This privacy demonstration is conceptual. Production deployment would require appropriate legal, institutional, security and data-governance controls.
